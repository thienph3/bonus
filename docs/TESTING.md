# TESTING

## Quick Start

```cmd
cd debt_matching

:: Pure Dart tests (no Flutter SDK needed, runs in WSL/Linux/CI)
dart test test/parse_utils_test.dart test/calculate_fifo_test.dart test/export_builder_test.dart test/import_parser_test.dart

:: Flutter unit + widget tests (headless)
flutter test

:: Integration test (launches real Windows app)
flutter test integration_test/ -d windows
```

## Running in CI

```yaml
- run: dart test test/parse_utils_test.dart test/calculate_fifo_test.dart test/export_builder_test.dart test/import_parser_test.dart

# Flutter tests (needs Flutter SDK)
- run: flutter test
```

- Tests importing `app_database.dart` require `flutter test` (pulls `flutter_riverpod` → `dart:ui`)

- Test fixtures are committed — no need to regenerate unless schema changes
